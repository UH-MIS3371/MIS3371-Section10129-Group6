# 04 — Requirements

## Functional

- The system should capture all student, advisor, and appointment information entered
- The system should assign a unique appointment ID and initial status
- The system should allow a student to request an appointment with an advisor
- The system should require a student to type reason for appointment
- The system should require a student to pick a date and time through a calendar
- The system should require a student to choose appointment type (in-person/virtual)
- The system should show feedback as to why a request was denied if it was (due to which business rule)

## Nonfunctional

- The system should have required field feedback to identify what information the student entered incorrectly
- The system should work on both laptops and mobile devices
- The system should protect student and advisor data
