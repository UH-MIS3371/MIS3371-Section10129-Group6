# 05 — User Stories + Acceptance Criteria

## Student

As a student, I want to request an appointment with an advisor and know that my request was received.

- **Acceptance:** Given valid required data, when I submit, I receive a request ID and a Submitted status.

As a student, I want to view the status of my request, so I know whether my appointment has been scheduled.

- **Acceptance:** Given an existing request, when I view it, the status and latest update on my request are shown.

## Advisor

As an advisor, I want to have some degree of automation of students' advising requests, so they're approved/denied according to my schedule.

- **Acceptance:** Given a student request, when they send a request, they receive feedback: whether their appointment is validated, or if not, why.
