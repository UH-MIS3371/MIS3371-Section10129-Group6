# Week 8 — Backend Testing

These tests exercise the request validation rules in `backend/backend.js`: PSID must contain seven digits, email must end in `@cougarnet.uh.edu`, and the requested date must be after today.

Run the tests from the repository root with:

```sh
node backend/test-backend.js
```

## Test cases and results

| # | Case | Input variation | Expected result | Actual result | Outcome |
|---|---|---|---|---|---|
| 1 | Invalid PSID | PSID is `1` | Rejected: PSID must be seven digits | Rejected: `The PSID length is incorrect` | Pass |
| 2 | Invalid email | Email is `diana@gmail.com` | Rejected: email must use the Cougarnet domain | Rejected: `Please enter the correct domain` | Pass |
| 3 | Past date | Date is `2006-10-18` | Rejected: requested date is in the past | Rejected: `The selected date can not be in the past` | Pass |
| 4 | Today's date | Date is generated by `getTodayString()` | Rejected: requested date cannot be today | Rejected: `The selected date can't be today` | Pass |
| 5 | Valid future request | Valid PSID and email; date is `2027-10-18` | Accepted with `success: true` | Accepted with `success: true` and status `Submitted` | Pass |
| 6 | Tomorrow's date | Valid PSID and email; date is generated as tomorrow | Accepted with `success: true` | Accepted with `success: true` and status `Submitted` | Pass |

All six cases matched their expected success/failure results when `node backend/test-backend.js` was ran. Transaction IDs and submission timestamps are generated dynamically, so they vary between runs.
