## Team Norms

Respond within 24 hours Mon-Fri. Channel messages through a main channel and communicate with each other on missed commitments.

## Git Workflow

Pull & sync before starting to code. Create branches for each feature to keep the main branch as clean as possible. Communicate commits clearly and have the Git / Integration lead do a final review of PRs and merge conflicts.

## Accountability

We will all be maintaining an understanding of the codebase, not a lower-level understanding of each line of code, but a higher-level understanding of the project directory, and why we've made certain decisions.
