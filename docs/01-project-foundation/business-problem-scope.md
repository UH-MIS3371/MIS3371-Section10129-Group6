# 01 — Business Problem + Scope

Students are having a hard time scheduling appointments with advisors. There's no online infrastructure, so they must go in person to schedule an appointment and view available times; sometimes advisors aren't even there to speak. This project will create a website in which students can request an academic advising appointment.

## In-Scope

Submit an academic advising appointment request, validate the request with business rules and advisor availability, and show status upon confirmation/failure.

## Out-of-Scope

Using actual UH students and UH advisors for advising appointment, sending an actual confirmation link upon confirmation, having a complete advisor request platform.
