# 03 — Main Transaction

**Students schedule an appointment with an academic advisor.**

- **Trigger:** Student needs to schedule an appointment with an advisor
- **Inputs:** Student ID, school email, advisor name, appointment date/time, reason for appointment
- **System Action:** Check required data and advisor availability; assign request ID/status
- **Outcome:** Confirm appointment for standard path or reject due to advisor conflicts or business rule violations
- **Official Record:** Request ID, student, purpose, appointment date/time
